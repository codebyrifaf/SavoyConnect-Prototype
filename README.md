# SavoyConnect — High-Fidelity Application Prototype

A high-fidelity interactive prototype of **SavoyConnect**, developed during my internship at **DLTD Software Company**.

The prototype was designed to demonstrate the complete user experience and functional flow of a proposed Savoy customer engagement platform, covering customer authentication, ice cream discovery, ordering, loyalty rewards, health and nutrition, recipes, community engagement, gamification, sustainability, store discovery, payments, customer support, and other core application features.

This repository represents the **prototype and frontend interaction layer**, not the production backend or final deployed application.

---

## Project Overview

SavoyConnect is envisioned as a comprehensive digital platform connecting Savoy customers with the brand through personalized experiences, ordering, rewards, community features, health-oriented information, gamification, and sustainability initiatives.

During my internship at **DLTD Software Company**, I worked on a highly detailed prototype to translate the proposed application concept into an interactive user experience.

# Prototype vs Production Application

It is important to distinguish the current repository from a production application.

| Area | Prototype | Production |
|---|---|---|
| UI | Implemented | Requires production implementation |
| Navigation | Interactive | Production routing required |

| Database | Local/static data | Production database required |
| Orders | Simulated | Backend order processing required |
